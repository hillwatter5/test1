# Hello World 单页面

这是一个纯静态的 **Hello World 单页面**（无依赖），适合用来快速验证静态托管、CDN、Nginx、对象存储等部署链路。

## 本地预览

### 方式 1：直接打开

双击打开 `index.html` 即可。

> 注意：浏览器对「直接打开本地文件」的剪贴板权限可能更严格，页面里的“复制文本”按钮可能会失败；用本地服务器方式预览会更稳定。

### 方式 2：本地起一个静态服务器（推荐）

在项目根目录运行：

```bash
python3 -m http.server 5173
```

然后在浏览器访问：`http://localhost:5173`
